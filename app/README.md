# 应用目录 / App Directory

这个目录包含生成式内容卡片项目的 Next.js 应用代码。

完整的项目背景、功能说明、环境变量、启动方式和隐私注意事项请查看根目录的 `README.md`。

## 快速启动

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

默认访问地址：

```text
http://localhost:3000
```
